# ふるさと納税かんたんナビ

はじめてふるさと納税をする人が、画面の案内どおりに進むだけで「上限額の確認 → 手続方法の判定 → サイト選び → 寄付 → 控除の手続き → 翌年の確認」までたどれるスマホ向けWebアプリです。

- 1ファイル（`index.html`）の素の HTML / CSS / JavaScript
- 氏名・住所・年収などは入力しません。進み具合と、採用した上限の目安を端末（localStorage）に保存します
- 制度の内容は変更されることがあります（2026年9月時点で総務省・国税庁の案内を確認）

## 姉妹アプリからの共有

同じオリジンの節税・資産形成ナビが保存した `setsuzeiNavi.share.v1` を読み、今年の `year` と有効な `donationLimit` があるときだけ STEP 2 にカードを表示します。「この金額を使う」で `furusatoNavi.v3` の `donationLimit: {year, amount}` に保存します。入力や金額を URL・外部へ送りません。
