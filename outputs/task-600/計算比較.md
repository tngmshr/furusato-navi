# 計算・入力出力の修正前後比較（タスク600）

本体に税額・上限の内部計算器はなく、SCREENS内の固定例と外部リンクがある。下表は表示・案内の入出力比較であり、新しい個人別計算器の実装ではない。変更前は before.json の作業前画面スナップショットで確認できる。

| 入力・前提 | 修正前の出力 | 修正後の出力・扱い |
| --- | --- | --- |
| 年収500万円・独身の会社員 | 上限約6万円、60,000円は範囲内という固定例 | 年収だけで上限を出さない。所得・社会保険料・家族構成・他控除・手続方法、対象年分を確認して外部計算等へ |
| 年間合計60,000円の寄付 | 上記年収と結び付けて軽減58,000円・負担2,000円 | 「本人の控除上限内で必要な手続きをした場合」という仮定に限定し、60,000−2,000＝58,000円の軽減目安、60,000−58,000＝2,000円の年間負担目安 |
| 同60,000円、確定申告 | 所得税約5,900円＋住民税約52,000円 | 固定内訳は表示しない。既納税額等により還付または納付減額、寄付年分の所得税と翌年度の住民税に反映と案内 |
| 同60,000円、返礼品 | 最大約18,000円分、差し引き最大約16,000円分お得 | 調達費用を市場価値に換算しない。固定金額・価値比較図・aria-labelを撤去 |
| 同60,000円、特例 | 毎月約4,800円（58,000÷12）、12か月 | 月割り表示を撤去し、翌年6月以降の住民税、各回の納付額は通知で確認へ |
| 合成所得割額235,500円・所得税率5%・係数1.021 | 旧514成果の感度計算57,479.12円（本体には存在しない） | 2,000＋235,500×20%÷(90%−5%×1.021)＝57,480.30円（小数第2位丸め）を検証のみ。本体へ新しい上限として転記しない |
| 514の合成入力：給与所得3,560,000円、社会保険料750,000円、基礎控除1,040,000円、他控除なし | 本体の約5,900円と整合しない | 合成課税所得1,770,000円、5%を仮定した所得税等軽減概算2,960.9円を既存検査の再利用で確認。住民税側の上限等を満たす保証はなく、個別税額として表示しない |

根拠：[国税庁の控除計算・限度](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1155.htm)。合成入力の由来・留保は[514修正案P01](../task-514/修正案.md)に従う。給与所得別表第五・税率判定差・他控除・端数処理等の未確認は継続。旧514成果とその算術誤差は原本保全し、本書で区別した。

外部シミュレーターへ年収・個人情報を入力する検証は実施していない。ブラウザ検査はダミーの進み具合だけを独立したローカル環境に保存し、本番や普段のブラウザのデータを変更していない。
